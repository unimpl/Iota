# Iota Web

The user-pinned reference is ChatGPT: a quiet neutral sidebar, spacious conversation column, restrained header and a rounded multiline composer. This is an operating interface; execution state and the next available action take priority over decoration.

Use system sans-serif typography, monospace only for code and paths, white and charcoal surfaces with matching light/dark modes. Use consistent stroked SVG icons. User messages align right in subtle filled bubbles; assistant replies have readable Markdown and no surrounding card. Tool activity and reasoning use disclosures. Errors and pending questions remain visible near their relevant action.

At narrow widths, the sidebar becomes a dismissible drawer; the composer stays reachable and content fits without horizontal page scrolling. Keyboard focus, reduced motion, connection states and busy controls are explicit.
