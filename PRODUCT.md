# Iota

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Go SDK and HTTP server; React and TypeScript client, as requested.

## Users

A single user working on local projects through the standalone CLI or browser.

## Product Purpose

Run the same coding agent through either interface, sharing configuration and saved sessions.

## Capabilities and Constraints

The SDK owns the model and tool loop. The CLI remains standalone. Each open session has one Agent owner and its own working directory. Browser disconnection does not cancel execution. HTTP is served directly; a gateway may terminate HTTPS. Existing planning, progress, compaction, skills, and user-input capabilities remain available.

## Brand Commitments

The user requested a ChatGPT-style chat interface. Copy is concise and technical. No fabricated example conversations or claims.
